How it works

Three steps. No accounts, no uploads.

Drop runs a small web server on your computer for as long as you say. Everything stays on your local network.

  1. Run it

    drop report.pdf in your terminal. Folders work too; they arrive as a .tar.

  2. Scan it

    Point a phone camera at the QR code, or open the link on any laptop on the same Wi-Fi.

  3. Done

    They tap Download. When the timer ends, or you press q, the link stops working.

Install

One line, then you're sharing.

A standalone binary for macOS and Linux. No Bun or Node needed.

macOS and Linux

Downloads the right binary for your machine, checks its SHA-256, and installs it to ~/.local/bin.

curl -fsSL https://raw.githubusercontent.com/husseymarcos/drop/main/install.sh | sh

With Bun

bunx @husseymarcos/drop ./report.pdf
npm install -g @husseymarcos/drop

The npm package runs on Bun, so install Bun first if you go that way.

Direct downloads

Latest release binaries. Verify them against checksums.txt.

  • macOS · Apple silicon arm64
  • macOS · Intel x64
  • Linux x64
  • Linux arm64

Then chmod +x it and move it onto your PATH. Windows and Homebrew are on the way.

Docs

Everything in drop --help

Options

<path>File or folder to share. Same as -f, --file.
-t, --timeHow long the link works: 90s, 5m, 1h, or seconds. Default 5m.
-p, --portPort to listen on. Default 8080, or 80 with -a. Moves up if taken.
-a, --aliasAlso publish <name>.local. The numeric link is still printed for Android.
--hostIP or interface (en0) to put in the link when a VPN or second adapter gets picked.
--max-uploadLargest upload drop receive accepts. Default 1gb.
-v, --versionPrint the version.
-h, --helpShow help.

Examples

  • drop ./report.pdfShare a file for five minutes.
  • drop ./photos -t 30mShare a folder as a .tar for half an hour.
  • drop video.mp4 --host en0Use the en0 address in the link.
  • drop receive -t 10m --max-upload 2gbOpen a page where others can send files to you. Uploads are off unless you run this.

While it runs: q or Ctrl+C stops the link at once.

The fine print

What Drop promises, and what it doesn't.

  • The link stops when time is up. When the timer ends or you press q, Drop closes the server, including downloads in progress.
  • It stays on your network. Drop never contacts an outside service. Files go straight from your computer to theirs.
  • Links are hard to guess. Each one ends in a random 8-character token.
  • It's plain HTTP, not encrypted. Others on the same network could see the traffic. Skip untrusted Wi-Fi for private files.
  • It doesn't delete anything. Your shared file stays where it is on disk. Uploads in receive mode live in memory until Drop exits.
